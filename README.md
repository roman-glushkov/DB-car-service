# AutoPro — фронтенд рабочего места автосервиса

Это первая фронтенд-версия по ТЗ. База данных, API и авторизация намеренно не подключены.

## Что реализовано

- Дашборд администратора;
- клиенты;
- автомобили и история обслуживания как концепция;
- заказы-наряды и статусы;
- сотрудники с активным/неактивным статусом;
- справочник работ;
- склад запчастей и индикация низкого остатка;
- оплаты;
- статистика;
- поиск/фильтры как UI-заглушки;
- формы создания записей как UI-заглушки;
- большая фотолента автомобилей и выполненных работ;
- адаптивная версия для телефона.

## Соответствие ТЗ

По ТЗ сайт является внутренним рабочим местом администратора, без клиентского кабинета и клиентской авторизации. Основные сущности: clients, cars, employees, order_statuses, orders, work_types, order_works, parts, order_parts, payments.

Сейчас вместо БД используются демонстрационные данные в `script.js`. Структуру экранов специально сделал так, чтобы позже API можно было подключить без переделки всей визуальной части.

Источник требований: приложенный файл ТЗ.

## Фото

Фото автомобилей используются как внешние демонстрационные изображения Unsplash. Это именно заглушки для интерфейса, а не фотографии конкретного автосервиса.

## Запуск

Откройте `index.html` в браузере.

Для следующего этапа логично подключить:
1. PostgreSQL/другую БД;
2. backend API;
3. реальные CRUD-операции;
4. расчёт суммы заказа из работ и запчастей;
5. списание склада;
6. историю автомобиля;
7. реальные графики и статистику;
8. загрузку фотографий выполненных работ.
