# AutoPro — автосервис с MariaDB

Проект подключён к реальной реляционной базе данных через небольшой backend API.

Архитектура:

`браузер (HTML/CSS/JS) -> Express API -> MariaDB autoservice`

DataGrip нужен только для просмотра и администрирования базы. Сайт напрямую к DataGrip не подключается.

## Что уже связано с БД

- главная: количество активных заказов, выручка, автомобили, низкие остатки;
- клиенты: чтение, поиск, создание;
- автомобили: чтение, поиск, создание, история заказов;
- сотрудники: чтение, создание;
- виды работ: чтение, создание;
- запчасти: чтение, поиск, создание;
- заказы: чтение, поиск/фильтры, создание, карточка заказа;
- добавление работ в заказ;
- добавление запчастей в заказ со списанием остатка в транзакции;
- оплаты: чтение и создание;
- статистика по реальным платежам и выполненным работам.

## 1. База данных

Создай базу `autoservice` и импортируй:

`database/schema-dump.sql`

В DataGrip: ПКМ по `autoservice` -> SQL Scripts -> Run SQL Script.

Чтобы сразу увидеть интерфейс с данными, после схемы можно выполнить:

`database/seed-demo.sql`

Seed необязательный и предназначен только для демонстрации.

## 2. Node.js

Нужен Node.js 20+.

Проверка:

```powershell
node -v
npm -v
```

## 3. Настройка подключения

В корне проекта скопируй `.env.example` в `.env` и впиши пароль `root`, который задавал при установке MariaDB:

```env
DB_HOST=127.0.0.1
DB_PORT=3306
DB_USER=root
DB_PASSWORD=ТВОЙ_ПАРОЛЬ
DB_NAME=autoservice
PORT=3000
```

`.env` добавлен в `.gitignore`, пароль в Git не попадёт.

## 4. Установка и запуск

Открой PowerShell в папке проекта:

```powershell
npm install
npm start
```

Открой:

`http://localhost:3000`

Важно: `index.html` двойным кликом больше открывать не надо. Страницу отдаёт сервер Node.js.

## 5. Проверка API

В браузере открой:

`http://localhost:3000/api/health`

Ожидается JSON примерно такого вида:

```json
{"ok":true,"version":"13.x...","database_name":"autoservice"}
```

## Структура проекта

- `index.html` — UI;
- `style.css` — оформление;
- `script.js` — запросы из браузера к API и отрисовка данных;
- `server.js` — Express API и SQL-запросы к MariaDB;
- `.env` — локальные реквизиты подключения (создаётся вручную);
- `database/schema-dump.sql` — схема БД;
- `database/seed-demo.sql` — тестовые данные.
